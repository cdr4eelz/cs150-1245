Pynq-Z2 and/or Arty-A7-100 are the explicit targets. Compared to ancient XUP-kdkd board, it is a different world of technology, including Vivado vs ISE tools.

NOTE: Pynq v1 is not very different from v2 ("-z2"), mostly to do with the audio chip it uses. However, this project focuses solely on Z2 version.

Pynq-Z2 challenges:
  HDMI (easy, 2 ways): Approach is to get example code to function, then adapt it.
    Use the backward compatibility with DVI signalling!
    Use a Digilent code/hw library to generate TMDS (as in DVI).
  DRAM (hard, needs AXI): DDR access on Pynq is indirect via AXI bus for DMA
    Start without DDR access, substituting small BlockRAM & CLUT
    Use minimized raster graphics output (to HDMI) then add raster.
    Migrate 

If Pynq DDR-DRAM access can be done (via AXI bus), or if enough BlockRAM for
    a frame-buffer is available (with CLUT perhaps), then the HDMI/DVI video
    output is already proven and the rest is simplifying the CPU components.
If Pynq is too hard to deal with for frame-buffer, then Arty-S7 100 has
    standard MIG method of memory access, though video output becomes PmodVGA.
