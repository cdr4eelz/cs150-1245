Pynq-Z2 is the explicit target. Compared to ancient XUP-kdkd board, it is a different world of technology, including Vivado vs ISE tools.

NOTE: Pynq v1 is not very different from v2 ("-z2"), mostly to do with the audio chip it uses. However, this project focuses solely on Z2 version.

Pynq-Z2 challenges:
	HDMI: Approach is to get example code to function, then adapt it.
		Use the backward compatibility with DVI signalling!
		Use a Digilent code/hw library to generate TMDS (as in DVI).
	DRAM: DDR access on Pynq is indirect via AXI bus for DMA
		Start without DDR access, substituting small BlockRAM & CLUT
		Use minimized raster graphics output (to HDMI) then add raster.
		Migrate
